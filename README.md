# Pokévrienden

Een Pokémon-achtig avontuur over een vriendenweekend. Nino, de verbinder van de groep, moet zijn verwilderde vrienden weer vangen: Quentin, Daan, Kevin, Tom en Stan. Met een koud blikje.

Alles (plaatjes, muziek en geluid) is in code gemaakt. Een fanproject in Pokémon-stijl, niet verbonden aan Nintendo of The Pokémon Company.

**Besturing:** pijltjes lopen, Z kiezen, X terug (ingedrukt: rennen), ESC menu, M geluid. Op de telefoon: joystick en knoppen op het scherm.
